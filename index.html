PERSONAL CHANNEL TOOL

Inventors Attic
YouTube MCP

A local publishing assistant for The Inventor’s Attic channel. Prepare a video, add its description and subtitles, then publish when the channel owner asks.

What the application does

This desktop tool connects a local MCP client, such as Codex, to the official YouTube Data API. It reads the owner’s channel and video details, uploads videos, updates titles and descriptions, adds caption tracks, and publishes selected videos.

New uploads are private by default. Publishing is a separate operation. The application checks the configured channel and video ownership before making changes.

Who it is for

This is a personal tool operated for The Inventor’s Attic | Invention Stories. It is not a public service accepting other users’ accounts. This website provides information; it does not sign visitors in or receive channel credentials.

Google access and data

The owner authorizes access through Google OAuth. The requested YouTube permission includes reading and managing videos and captions. Google groups this permission with broader capabilities, including deletion; the application exposes no deletion commands.

OAuth tokens are stored in the operator’s macOS Keychain. Tool results can be sent to the operator’s MCP client for the requested workflow. Read the privacy policy for storage, sharing, and revocation details.
