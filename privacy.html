Privacy policy

How Inventors Attic YouTube MCP handles data for the channel owner’s publishing workflow.

Operator and purpose

The application is a personal desktop tool operated for The Inventor’s Attic | Invention Stories. Contact: theinventorsattic@gmail.com. It uses Google account authorization only to carry out the owner’s requested YouTube channel operations.

Data accessed and used

The application accesses the authorized channel’s identity, upload list, video titles, descriptions, tags, language and visibility settings, processing status, basic video statistics, and caption-track details. It also processes local video and subtitle files chosen by the owner and the metadata supplied for them. Private video information may be included when the owner requests it.

This information is used to identify the correct channel, prepare and upload media, edit metadata, manage subtitles, publish selected videos, verify results, and prevent duplicate uploads. The application does not request Gmail, Google Drive, contacts, or payment access.

Storage and retention

OAuth access and refresh tokens are stored in the operator’s macOS Keychain. OAuth client configuration is stored in a restricted local file. Tokens and client configuration are not part of this public website or its source repository.

A local upload ledger stores file paths, file hashes, upload plans, video identifiers, progress, and results. Local media, captions, verification reports, and workflow records remain on the operator’s computer until the operator removes them. Revoking Google access does not automatically delete these local files or videos already stored by YouTube.

Where information goes

Selected videos, captions, and requested metadata changes are sent to Google’s YouTube API. Tool requests and results are exchanged with the operator’s MCP client. When Codex is used, returned channel information and workflow content may be processed by OpenAI under the operator’s account settings and OpenAI’s privacy policy. The application does not return OAuth tokens through its MCP tools.

The operator does not sell Google user data, use it for advertising, or use it to build or train the application’s own AI models. Data is used and shared only as needed for the requested publishing workflow, security, or applicable legal requirements. Inventors Attic YouTube MCP’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Your control

The owner can stop the local application and revoke its access in Google Account connections. The operator can remove the app’s Keychain entry and local data separately. YouTube videos and captions can be managed in YouTube Studio. Contact the address above with questions or deletion requests concerning locally retained data.

This website

This static informational site has no account form, analytics script, or tracking cookies added by the application. GitHub Pages hosts it and may process technical access logs, including IP addresses, under the GitHub privacy statement. This website does not receive OAuth callbacks, tokens, private channel data, or media uploads.

Updates

Changes to these practices will be reflected on this page with an updated date before new data uses begin.
